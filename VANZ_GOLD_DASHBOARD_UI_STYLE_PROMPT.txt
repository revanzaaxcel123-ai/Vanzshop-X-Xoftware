Saya ingin kamu meniru STYLE VISUAL / UI UX dashboard dari referensi berikut, BUKAN menyalin logic, backend, API, database, routing, atau fitur aplikasinya.

Gunakan desain dashboard admin premium dengan karakter berikut:

1. Tema utama: Vanz Gold Dark
- Background utama: #0b0a09
- Sidebar background: #100f0d
- Card utama: #161513
- Card secondary / hover: #1c1a17
- Input / field background: #0f0e0c
- Text utama: #f3eee4
- Text muted: #9a9387
- Accent gold utama: #e9b949
- Accent gold gelap: #c8912a
- Accent gold terang: #fff0c2
- Text di atas tombol gold: #1a1307
- Success: #3ddc84
- Danger: #ff6b6b
- Warning: #fbbf24
- Hindari pure black sebagai background utama.
- Border subtle dan glow gold tipis, jangan berlebihan.

2. Typography
- Gunakan "Plus Jakarta Sans" untuk seluruh UI.
- Gunakan "JetBrains Mono" untuk OTP, kode, API key, ID, atau data monospace.
- Heading bold 700–800 dengan sedikit negative letter spacing.
- Body sekitar 13–14px.
- Muted text sekitar 11–13px.
- Hierarchy jelas, jangan membuat tulisan terlalu besar.

3. Layout desktop
- Grid 256px sidebar + main content.
- Sidebar sticky kiri, full viewport height.
- Main padding sekitar 26px 32px 60px.
- Whitespace lega tetapi tetap padat seperti dashboard profesional.

4. Branding
- Logo uppercase, font-weight 800, letter-spacing sekitar 5px.
- Gunakan gold gradient dari #fff0c2 ke #e9b949 ke #c8912a.
- Subtitle kecil uppercase dan muted seperti ADMIN DASHBOARD.

5. Sidebar navigation
- Compact, padding sekitar 10px 12px, radius 11px, icon kiri.
- Default muted.
- Hover memakai secondary card.
- Active menu memakai card background, icon gold, dan indikator vertical gold 3px di sisi kiri.
- Jangan pakai menu kotak besar-besar.

6. Cards
- Background #161513.
- Border tipis subtle.
- Radius sekitar 18px.
- Shadow dark lembut.
- Header card padding sekitar 16px 20px.
- Body sekitar 18px 20px.
- Gap antar card sekitar 18px.

7. KPI cards
- Desktop 4 kolom, gap sekitar 14px.
- Padding 16px 18px.
- Icon kecil dalam rounded box dengan background gold transparan.
- Label kecil muted.
- Angka utama sekitar 28px dan font-weight 800.
- Jangan penuh dekorasi.

8. Dashboard grid
- Chart + secondary stats sekitar 1.6fr 1fr.
- Dua card sejajar sekitar 1fr 1fr.
- Gunakan gap 18px dan alignment konsisten.

9. Buttons
- Height sekitar 42px.
- Padding horizontal 16px.
- Radius 11px.
- Font-weight 700.
- Primary button pakai gradient gold #e9b949 -> #c8912a.
- Text tombol primary #1a1307.
- Hover cukup brightness sedikit naik.
- Danger button transparan dengan red text dan red border subtle.
- Small button height sekitar 32px.

10. Inputs / textarea / select
- Height sekitar 42px.
- Padding 0 13px.
- Radius 11px.
- Background #0f0e0c.
- Focus border gold + glow tipis.
- Label 12px, weight 700, muted.
- Help text 11.5px lebih redup.
- Select pakai arrow custom sederhana.

11. Toggle
- Rounded pill sekitar 44x25px.
- On = gold.
- Off = muted.
- Transition sekitar .2s.

12. Tables
- Clean dan compact.
- Header uppercase, 11px, letter-spacing sekitar 1.1px, muted.
- Cell padding sekitar 13px 16px.
- Border-bottom tipis.
- Hover row pakai gold transparent sangat tipis.
- Tidak pakai garis vertikal.
- Gunakan ellipsis untuk text panjang.

13. Badge / status
- Kecil, inline-flex.
- Font-size sekitar 11px.
- Weight 800.
- Padding sekitar 3px 8px.
- Radius 7px.
- Gold / success / danger / warning pakai transparent background yang sesuai.

14. OTP / code styling
- JetBrains Mono.
- Weight 700.
- Letter-spacing sekitar 1.5px.
- OTP pill boleh pakai gold gradient dan text gelap.

15. Icon button
- Sekitar 40x40px.
- Radius 11px.
- Background card.
- Border subtle.
- Hover icon gold.

16. Modal
- Overlay rgba(5,4,3,.6) + blur 5px.
- Modal card background, radius sekitar 20px.
- Shadow premium.
- Isi scrollable.
- Nyaman dipakai di mobile.

17. UX principles
- Clean.
- Premium.
- Dense tetapi tidak sesak.
- Hierarchy jelas.
- Jangan terlalu banyak gradient.
- Hindari glassmorphism berlebihan.
- Hindari neon glow berlebihan.
- Hindari card dalam card terlalu banyak.
- Spacing konsisten.
- Primary action mudah ditemukan.
- Destructive action jelas berbeda.
- Tabel mudah di-scan.
- Gunakan SVG outline icon, bukan emoji.

18. Responsive
- Breakpoint sekitar 980px.
- Sidebar desktop hilang.
- Main menjadi satu kolom.
- Main padding mobile sekitar 16px 14px 40px.
- Ganti sidebar dengan horizontal mobile tabs yang bisa di-scroll.
- 2-column grid menjadi 1 column.
- Table boleh horizontal scroll.
- KPI tablet 2 kolom.
- Breakpoint sekitar 560px: heading 20px, KPI number 24px, table padding diperkecil, grid kecil jadi 1 kolom.

19. Animation
- Sangat subtle.
- Fade + translateY sekitar 6px.
- Durasi sekitar .25s.
- Hormati prefers-reduced-motion.

20. Theme architecture

Jangan hardcode semua warna di setiap component.

Yang ingin ditiru hanya:
- background
- color palette
- visual theme
- sidebar design
- card design
- table design
- button design
- form/input design
- KPI design
- typography
- spacing
- border radius
- responsive behavior
- visual hierarchy
- overall UI/UX dashboard

JANGAN copy atau mengubah:
- backend
- API

- authentication
- business logic
- endpoint
- routing
- data structure
- fitur aplikasi

Adaptasikan style ini ke fitur dan struktur project yang sedang dikerjakan.
